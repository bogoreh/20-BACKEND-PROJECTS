# Weather Data Proxy

A beginner-friendly PHP application that fetches and filters weather data from third-party APIs.

## Features

- 🌤️ Fetch current weather data
- 📅 Get 5-day weather forecast
- 🔍 Filter results by temperature range
- 💾 Built-in caching system
- 📱 Responsive design
- ⚡ Fast and efficient API calls

## Setup Instructions

1. **Clone or download the project**

2. **Get an API Key**
   - Go to [OpenWeatherMap](https://openweathermap.org/api)
   - Sign up for a free account
   - Get your API key from the dashboard

3. **Configure the Application**
   - Navigate to `config/api_keys.php`
   - Replace `'your_api_key_here'` with your actual API key
