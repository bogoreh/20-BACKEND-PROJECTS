# User Management System - PHP CRUD API

A simple and clean User Management System with PHP CRUD API and responsive frontend.

## Features
- Create, Read, Update, Delete Users
- RESTful API
- Responsive Design
- Clean UI with Font Awesome Icons
- Form Validation
- Error Handling

## Installation

### 1. Prerequisites
- PHP 7.4 or higher
- MySQL 5.7 or higher
- Web Server (Apache/Nginx)
- Composer (optional)
